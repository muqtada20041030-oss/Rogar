بوت إيسكانور — النسخة المصححة

الملفات:
- escanor_bot_fixed.py : الكود، بدون توكن أو مفتاح مضمّن.
- .env : إعداداتك الحالية محفوظة منفصلة عن الكود.
- .env.example : قالب فارغ لإعداد نسخة جديدة.
- requirements.txt : المكتبات المطلوبة.

التشغيل:
1) ضع الملفات في مجلد واحد ولا تحذف ملف .env.
2) ثبّت المكتبات: python -m pip install -r requirements.txt
3) شغّل: python escanor_bot_fixed.py
4) لا ترفع ملف .env إلى GitHub ولا ترسله لأي شخص.

تنبيه أمني:
قيم الاتصال الأصلية كانت موجودة داخل الملف الذي أرسلته. تم نقلها كما هي إلى .env
لتبقى النسخة عاملة، لكن .env نص عادي وليس تشفيرًا. الأفضل إنشاء توكن جديد من BotFather
ومفتاح Gemini جديد بعد التأكد من إعداد النسخة، ثم استبدال القيم داخل .env.

إعدادات Gemini المهمة:
- GEMINI_TIMEOUT_SECONDS=15 : مهلة الطلب.
- GEMINI_QUEUE_WAIT_SECONDS=4 : ينتظر الطلب حتى 4 ثوانٍ إذا كانت الاتصالات مشغولة.
- GEMINI_MAX_CONCURRENT=2 : عدد طلبات Gemini المتزامنة.
- GEMINI_USER_COOLDOWN=3 : يحد التكرار السريع من نفس المستخدم.
- GEMINI_MODEL=gemini-2.5-flash : يمكن تغييره إذا لم يكن متاحًا لمشروع المفتاح.

حدود الفحص:
تم إجراء فحص ساكن للكود والتحقق من بناء Python، لكن لم يتم إرسال طلبات فعلية إلى Telegram أو Gemini
لأن ذلك يحتاج تشغيل البوت ومفاتيح فعالة واتصالًا خارجيًا. أخطاء الحصة أو الفوترة لدى Google لا يمكن
إصلاحها برمجيًا؛ الكود الآن يميّزها عن الضغط المؤقت ويعيد المحاولة مرة واحدة فقط للأخطاء المؤقتة.
